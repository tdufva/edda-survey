# EDDA Survey

A public, privacy-preserving thematic analysis of seven responses to the EDDA internationalisation survey.

The site keeps counts beside percentages, allows overlapping themes, documents interpretive limits, and does not publish timestamps or raw written responses. Its methodology is informed by Catherine D’Ignazio and Lauren F. Klein’s *Data Feminism*.

## Local development

```bash
pnpm install
pnpm run dev
```

## GitHub Pages

The `main` branch is deployed automatically through GitHub Actions.
